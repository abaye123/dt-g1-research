# DT G1 Menu Editor (Glyphix / ATS3085S)

עורך גרפי ויזואלי לקובץ התצורה של תפריט האפליקציות המובנה (`menu_list.cfg`) בשעונים חכמים מסוג DT NO.1 G1 ובשעוני שיבוט המבוססים על פלטפורמת החומרה Actions Semiconductor ATS3085S, שמריצים Glyphix OS.

> **⚠️ אזהרה: סכנת הפיכת השעון ללבנה (bricking)**
> שינוי קובצי תצורת מערכת בקובץ המערכת הנסתר כרוך בסיכון גבוה. אם `menu_list.cfg` ייפגם, ייחתך, או יפנה לנכסי GUI לא תקינים, מנוע הרינדור של Glyphix OS עלול לגרום לחריגת חומרה (Hard Fault / Null Pointer), ולכניסה ללולאת אתחול אינסופית (bootloop). היוצרים אינם אחראים למכשירים שניזוקו. המשך על אחריותך בלבד.

## הקשר טכני

באמצעות הנדסה לאחור הוכח ש-Glyphix Application Manager בפלטפורמה זו אינו מייצר AppID דינמיים עבור אפליקציות `.pkg` מותאמות אישית. במקום זאת הוא נשען על רשימה לבנה (whitelist) קשיחה בגודל 1600 בתים (`menu_list.cfg`).

הכלי מאפשר לנתח, לסדר מחדש, להסתיר ו"לחטוף" (hijack) משבצות מובנות כדי להפעיל אפליקציות `.pkg` מותאמות אישית (למשל, החלפת משבצת של אפליקציה מובנית שאינה בשימוש במזהה מותאם אישית), והכול בצורה בטוחה.

## מפרט הקובץ (`menu_list.cfg`)

* **מגבלת גודל:** בדיוק 1600 בתים (`0x640`). כל סטייה בגודל תקריס את המנתח הפנימי של השעון.
* **קיבולת:** 100 רשומות לכל היותר.
* **גודל רשומה:** 16 בתים (`0x10`) למשבצת.
* **סדר בתים:** Little Endian (`<IIII`).
* **מבנה:**
  * בתים 0-3: `uint32 AppID`
  * בתים 4-7: `uint32 IconID` (מצביע לנכס)
  * בתים 8-11: `uint32 NameID` (מצביע למחרוזת)
  * בתים 12-15: `uint32 Flags` (`1` = גלוי, `0` = מוסתר/מתעלמים)

## יכולות

* **ניתוח ואימות בטוחים:** מוודא ש-`menu_list.cfg` ששונה שומר על מבנה 1600 הבתים המדויק שהקושחה דורשת. משבצות שנמחקו מתאפסות בבטחה (zero-fill) ומוזזות לסוף המערך.
* **מיפוי ויזואלי:** מתרגם ערכי hex גולמיים של `AppID` לשמות אפליקציות קריאים לאדם, באמצעות מסד הנתונים `AppID_mapping.csv` הנטען באופן דינמי.
* **ניהול משבצות:** הזזה (למעלה/למטה), הסתרה (החלפת דגלי נראות) וניקוי משבצות אפליקציה.
* **תמיכה בחטיפה (Hijacking):** מאפשר להקצות `AppID` מובנים (למשל `0xC82C`) לקובצי `.pkg` מותאמים אישית (כמו PurrRock). מזריק אוטומטית ערכי ברירת מחדל בטוחים של `IconID` ו-`NameID` כדי למנוע קריסות רינדור ב-GUI במשבצות חדשות.

## דרישות

* Python 3.8+
* `tkinter` (ספרייה סטנדרטית של Python)
* `AppID_mapping.csv` (חייב להיות בתיקיית קובץ ההרצה/הסקריפט כדי שהמיפוי הוויזואלי יעבוד)
* PuTTY (או כל טרמינל טורי)
* `ser_set_real_u_py2.exe` (כלי יצרן לעיגון המחיצה הנסתרת של המערכת)

## שימוש: כיצד לשלוף (Dump) ולצרוב (Flash) את `menu_list.cfg`

כדי לגשת למחיצת המערכת הנסתרת (`/1:/`) של השעון, יש להשתמש בפרוטוקול תקשורת טורית (פקודות AT).

### שלב 1: עיגון (Mount) המחיצה הנסתרת
1. בשעון, היכנס להגדרות ושנה את **USB Mode** מ-`Mass Storage` ל-`Charging mode`.
2. חבר את השעון למחשב בכבל ה-USB. Windows יזהה יציאת COM טורית חדשה (למשל `COM3`).
3. הרץ את `ser_set_real_u_py2.exe`. כלי זה יעגן את מחיצת המערכת הנסתרת של השעון ככונן לוגי חדש במחשב.
   * *הערה:* שים לב לפלט הקונסולה של התוכנה. היא תדפיס את מספר יציאת ה-COM המדויק ואת קצב ה-baud הנדרש (בדרך כלל `2000000`).
4. פתח את הכונן החדש שעוגן ובדוק אם קיימת בו תיקייה בשם `custom`. אם לא, צור אותה ידנית.
5. **סגור את `ser_set_real_u_py2.exe`** כדי לשחרר את נעילת יציאת ה-COM.

### שלב 2: שליפה (Dump) של התפריט הנוכחי
1. פתח את PuTTY (או אמולטור טרמינל אחר).
2. צור חיבור **Serial** עם יציאת ה-COM וקצב ה-baud (`2000000`) שרשמת קודם.
3. פתח את החיבור ולחץ `Enter`. השעון אמור להשיב `OK`.
4. שלח את פקודת ה-AT הבאה כדי לאלץ את ממשק Glyphix לשמור את פריסת התפריט הנוכחית בתיקיית `custom`:
   ```text
   AT+WRX=saveMenu
   ```
5. השעון ייצור את הקובץ `menu_list.cfg` בתוך התיקייה `custom`.
6. סגור את PuTTY.
7. הפעל שוב את `ser_set_real_u_py2.exe` כדי לעגן את הכונן מחדש, נווט לתיקייה `custom` והעתק את `menu_list.cfg` למחשב.

### שלב 3: עריכה באמצעות DT G1 Menu Editor
1. הרץ `python dtg1_menu_editor.py` (או הפעל את קובץ ה-`.exe` המהודר).
2. לחץ על **Load menu_list.cfg** ובחר את קובץ ה-`.cfg` ששלפת.
3. שנה את המשבצות הנדרשות (הוספה, עריכה, הזזה או החלפת נראות).
4. לחץ על **Save menu_list.cfg**. הכלי יאמת אוטומטית את אורך המערך ויארוז מחדש את הקובץ הבינארי בצורה בטוחה.

### שלב 4: צריבה חזרה לשעון
1. ודא שהשעון עדיין מחובר ושמחיצת המערכת מעוגנת באמצעות `ser_set_real_u_py2.exe`.
2. העתק את `menu_list.cfg` ששינית חזרה לתיקייה `custom` בשעון, תוך דריסת הקובץ הקיים.
3. נתק את השעון מכבל ה-USB.
4. **הפעל מחדש את השעון.** עם האתחול, מנהל ה-UI ינתח את קובץ ה-`.cfg` החדש ויעדכן את תפריט האפליקציות שלך.
