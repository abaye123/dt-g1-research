# 🐾 PurrLaunch

**PurrLaunch** הוא משגר (launcher) ומנהל חבילות מלא לשעונים חכמים המבוססים על Glyphix OS (למשל DT NO.1 ותואמים, על פלטפורמת החומרה Actions Semiconductor ATS3085S / Zephyr RTOS).

בגלל המערכת הסגורה של השעונים החכמים, הפעלה והתקנה של אפליקציות צד שלישי "מהקופסה" מוגבלות מאוד. PurrLaunch פותר את הבעיה: הוא מאפשר להתקין כל אפליקציית `.pkg` ישירות מזיכרון ה-flash ה-USB של השעון, להפעיל אותה, ולהסיר אותה בבטחה.

כדי לעקוף את מגבלות המערכת, המשגר מתחזה לאפליקציית המערכת **Wooden Fish**.

---

## ⚙️ התקנת PurrLaunch בשעון

מכיוון שבשעון אין בתחילה מנהל קבצים מובנה, ההתקנה הראשונה של המשגר עצמו מתבצעת בערוצים הרגילים:

1. הורד את [ארכיון ה-zip של הגרסה האחרונה](https://github.com/purrrock/PurrLaunch/releases/latest). בתוך הארכיון תמצא את חבילת המשגר `com.xfaith.woodenfish.pkg` ואת כלי השירות `ser_set_real_u_py2.exe`.
2. התקן את המשגר בשעון. בהתאם ליכולותיך, אפשר לעשות זאת:
   * דרך אפליקציית הליווי הסטנדרטית בסמארטפון.
   * או ידנית (באמצעות כלי מפתחים): השתמש בכלי `ser_set_real_u_py2.exe` כדי להניח את קובץ ה-`.pkg` בשעון בתיקייה `\gui\apps` של מחיצת המערכת, ולערוך ידנית את הקובץ `\gui\pkgs.db` על ידי הוספת הבלוק הבא:

```json
{
  "apps": {
    "com.xfaith.woodenfish": {
      "uri": "pkg://com.xfaith.woodenfish"
    }
  },
  "dials": {}
}
```

   לאחר מכן יש להוסיף את Wooden Fish המזויף שלנו לתפריט השעון באמצעות הכלי [dtg1-menu-editor](https://github.com/purrrock/dtg1-menu-editor).

לאחר ההתקנה, סמל "Wooden Fish" בתפריט השעון יהפוך לנקודת הכניסה אל PurrLaunch.

## 📦 כיצד להתקין אפליקציות חדשות (.pkg)

עם PurrLaunch, התקנת אפליקציות, משחקים או כלי עזר חדשים הופכת לפשוטה:

1. בשעון, היכנס להגדרות ושנה את **USB Mode** מ-`Mass Storage` ל-`Charging mode`.
2. **חבר את השעון למחשב:** השתמש בכבל המגנטי המצורף.
3. הרץ את `ser_set_real_u_py2.exe` (נמצא בארכיון ה-zip שהורדת). כלי זה יעגן את מחיצת המערכת הנסתרת של השעון ככונן לוגי חדש במחשב (המחשב יזהה את השעון כשני כונני USB).
4. **העתק את הקבצים:** העבר את האפליקציות שהורדת (קובצי `.pkg`) לתיקייה `/data/mass` בכונן המערכת של השעון (בדרך כלל השני מבין הכוננים שעוגנו).
5. **נתק והפעל מחדש את השעון:** הוצא את ההתקן בבטחה והפעל מחדש דרך תפריט השעון.
6. **פתח את המשגר:** בתפריט הראשי של השעון, מצא את האפליקציה **Wooden Fish** והפעל אותה.
7. **התחל בהתקנה:**
   * הקש על כפתור **Menu**, ואז בחר **File Manager**.
   * ודא שהלשונית **Mass** פעילה. תראה רשימה של כל הקבצים, כולל קובצי ה-`.pkg` שהועתקו.
   * הקש על קובץ האפליקציה (`.pkg`) הרצוי כדי להתחיל את תהליך החילוץ הדו-שלבי.
8. **ניקוי אוטומטי:** לאחר חילוץ מוצלח, המשגר יציע למחוק את קובץ ה-`.pkg` המקורי מכונן ה-USB (כפתורים **Keep** / **Delete**). מומלץ להסכים כדי לא להעמיס על זיכרון השעון.

לאחר ההתקנה, חזור למסך הראשי בהחלקה ימינה - סמל האפליקציה החדשה יופיע שם.

## 🚀 שימוש והפעלה

כשתפתח את PurrLaunch, תראה רשימה של כל אפליקציות צד שלישי המותקנות (הרשימה ממוינת אוטומטית לפי סדר אלפביתי).
פשוט **הקש על השם או על הסמל** של כל אפליקציה כדי להפעיל אותה מיד.

*כדי לחזור למסכי המשגר הקודמים או לצאת אל פני השעון, השתמש בהחלקת המערכת משמאל לימין או בכפתור הפיזי בשעון.*

---

## 🧰 כלי מערכת (Menu)

במסך הראשי, הקש על כפתור **Menu** כדי לפתוח כלי מערכת נוספים:

* **📊 System Info:** מציג נתוני מכשיר מפורטים (דגם, סביבת הרצה - שעון/אמולטור, צורת התצוגה והרזולוציה), וכן ניטור זיכרון (שטח פנוי בכונן ה-flash ופרופיל ה-RAM שהוקצה).
* **📁 File Manager:** מנהל מובנה לניווט בכוננים הווירטואליים הנסתרים של השעון (`mass` - אחסון flash ציבורי, `files` - ארגז חול (sandbox) מבודד, `cache` - קבצים זמניים).
  * **התקנת חבילות:** הקשה על כל קובץ `.pkg` מפעילה אוטומטית את המתקין.
  * **מחיקת קבצים:** מאפשרת מחיקה בטוחה של כל קובץ שנשאר מיותר (כפתור **DEL**) בלי לחבר למחשב.
  * **מציג טקסט:** מזהה אוטומטית פורמטי טקסט (`.txt`, `.log`, `.md`, `.json`, `.xml`, `.ux`, `.js` ועוד) ומאפשר לקרוא את תוכנם במסך מלא ישירות מפרק כף היד.
* **🗑️ Manage / Delete Apps:** נכנס למצב ניהול של החבילות המותקנות כדי להסיר אותן.

---

## 🗑️ כיצד להסיר אפליקציות

אם אינך זקוק עוד לאפליקציית צד שלישי שהותקנה:

1. פתח את PurrLaunch ועבור אל **Menu**.
2. בחר **Manage / Delete Apps**.
3. מצא ברשימה את האפליקציה הלא רצויה ולחץ על כפתור **DEL** האדום.
4. יופיע דיאלוג אישור. הקש **Uninstall**.

המערכת תמחק את האפליקציה כולה ותנקה את כל הקבצים הזמניים והמטמון (cache) שלה.

## ⚠️ תאימות ואזהרות

* הפרויקט נבדק בשעונים חכמים **DT NO.1 G1** (שבב ATS3085S, Glyphix OS).
* הגנה מובנית מונעת ממך למחוק בטעות את PurrLaunch עצמו דרך הממשק שלו, או להציג שירותי מערכת קריטיים. אם עליך להסיר את המשגר, עשה זאת דרך אפליקציית הליווי בסמארטפון או ידנית דרך USB.
* השתמש בחבילות `.pkg` של צד שלישי ממקורות מהימנים בלבד.
