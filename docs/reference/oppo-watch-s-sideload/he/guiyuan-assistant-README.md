## תהליך שימוש

1. מתקינים את ה-APK הזה על **הטלפון** (לא על השעון - זו לא אפליקציית שעון)
2. מדליקים את השעון ומחברים אותו לטלפון בבלוטות' (שעוני OPPO מגיעים מהמפעל כבר מקושרים לשירותי OPPO Health / quick-connect)
3. פותחים את Guiyuan Assistant:
   - **Connect** (连接): מאתר שירות אחד -> `连接服务: com.heytap.health` -> `连接成功` (מחובר)
   - **Device info** (设备信息): אמור להחזיר `{"brand":"OPPO","model":"OWW262",...}` (הזהות של ה-OWS)
4. **Install app** (安装应用): בוחרים חבילת `.pkg`/`.rpk` בבורר הקבצים -> כשביומן מופיע
   `安装应用 成功 {"code":200,"msg":"success"}` היא מותקנת
5. **Launch app** (启动应用): מזינים את שם החבילה -> 200 פירושו שהופעלה (שימו לב: ייתכן שלא תעלה לחזית; הפעלה מ-PurrLaunch / משולחן העבודה אינטואיטיבית יותר)
6. **Device log** (设备日志): זרם יומן RPC בזמן אמת מצד השעון (כלי מצוין לאיתור תקלות, ראו DEV_GUIDE §6.2 במאגר)

## ששת הכפתורים

| כפתור | פעולה | הערות |
|---|---|---|
| 连接 (Connect) | מתחבר לשירות ה-bridge של אפליקציית Health | צריך להתחבר מחדש אחרי כל פתיחה מחדש |
| 设备信息 (Device info) | קורא את זהות השעון (דגם/גרסה/VID) | מאמת את ה-bridge |
| 检查安装 (Check install) | מחזיר 200 + true/false | ⚠️ סמנטיקה לא אמינה, אין להשתמש בו כקריטריון להתקנה |
| 安装应用 (Install app) | בחירת קובץ SAF -> דחיפת החבילה והתקנה | כל שם קובץ מתאים, התוכן קובע הכול |
| 启动应用 (Launch app) | הפעלה לפי שם חבילה | 5001 = החבילה לא קיימת |
| 设备日志 (Device log) | זרם יומן RPC מצד השעון | רשומות `app.life` / `lvgl` / `mas.ffi` |
